Video Assistant Referee

La VAR est une technologie utilisée dans le football pour assister les arbitres grâce à l’analyse vidéo.


Elle permet de vérifier certaines décisions importantes :
  • Buts
  • Hors-jeu
  • Cartons rouges
  • pénalty

La VAR fonctionne avec :
  • Plusieurs caméras haute définition
  • Une salle de contrôle vidéo
  • Transmission des images en temps réel
  • Communication entre arbitres

Voici les Technologies utilisées :
  • Caméras 4K / haute vitesse
  • Réseaux à haut débit
  • Logiciels d’analyse vidéo
  • Systèmes de replay et ralentis

Voici les Avantages :
  • Réduction des erreurs d’arbitrage
  • Plus de justice dans les décisions
  • Amélioration de la crédibilité des matchs

Voici les Limites :
  • Décisions parfois longues
  • Débat sur l’interprétation humaine
  • N'intervient pas sur toutes les situations

Lien avec le BTS SIO SISR :
  • Réseaux → transmission vidéo en temps réel
  • Systèmes → serveurs de traitement vidéo
  • Infrastructure → installation des équipements
  • Sécurité → protection des flux vidéo
