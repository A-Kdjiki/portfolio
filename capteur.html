Capteur Biométrique


Les clubs utilisent des capteurs connectés pour analyser les performances physiques des joueurs.
Ces capteurs sont intégrés dans des gilets portés sous le maillot.
Voici les technologies utilisées:
  • GPS / GNSS → position sur le terrain
  • Accéléromètre → mouvements
  • Gyroscope → orientation
  • Capteur cardiaque → rythme cardiaque
  • Réseau sans fil → transmission des données

Voici Données collectées:
  • Distance parcourue
  • Vitesse maximale
  • Accélérations
  • Intensité des efforts
  • Fréquence cardiaque
  • Fatigue

Voici l'Utilité:
  • Amélioration des performances
  • Prévention des blessures
  • Analyse tactique
  • Suivi individuel

    • Voici le Lien avec le BTS SIO SISR:
    • Réseaux → transmission des données
    • Systèmes → stockage sur serveur
    • Sécurité → protection des données
    • Infrastructure → mise en place des capteurs
